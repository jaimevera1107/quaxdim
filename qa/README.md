# Test and benchmark tools

- `run_suite.py` consolidates local regression and optional backend tests.
- `benchmark_v08.py` generates synthetic data and measures execution.
- Results are written to `reportes/` and must not be committed.
- `Ejecutar_Pruebas_Completas.cmd` is the recommended Windows entrypoint.

Benchmarks are not comparable when the engines do not perform identical work.
